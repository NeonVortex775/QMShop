青冥商城 · 自定义界面说明
================================================================

一、文件放哪
   plugins/QingMingShop/gui/*.yml
   每个 yml 就是一套界面，文件名随便起（中文也行）。

二、match 怎么用
   match: "*"          所有商店通用（默认.yml 就是这种）
   match: "灵材"       只给 shops/灵材.yml 这个商店用
   选模板的优先级：先找 match 等于商店名的，找不到再用 "*" 的。
   不写 match 字段，按 "*" 处理。

三、材质（贴图）放哪
   贴图仍然放客户端资源包：
      <客户端>/.minecraft/resourcepacks/DragonCore/
   yml 里 texture 写相对这个目录的路径，例如：
      texture: "商城/边框_左上.png"
   想加自己的图，丢进 resourcepacks/DragonCore/你的文件夹/，
   然后 texture 写 "你的文件夹/图.png"。
   注意：材质必须在客户端资源包里，插件目录里的 png 客户端读不到。

四、插件会自动填数据的组件名（名字必须这么起）
   行1名 / 行2名 …      商品名
   行1价 / 行2价 …      数量 × 价格
   行1图标 …            商品图标
   行1需求1 … 行1需求4   第 1~4 项需求的图标
   行1选择字            选中时显示「已选」，否则「选择」
   标题                 商店标题
   页码                 当前页 / 总页
   上一页 / 下一页       按页数自动显隐
   面板xxx              没选中商品时整组隐藏
   提示xxx              没选中商品时显示

   行组件里可以用 {index}（商品下标）和 {row}（行号），
   其它地方可以用 {w} {h} {shop} {title} {page} {pages} {qty} {rows} {step} {big}

五、按钮怎么调插件
   actions:
     click: "方法.发包('QingMingShop', 'select', '{index}')"

   可选动作：
     select {index}     选中商品（{index} 会被换成真实下标）
     qty 1 / qty -1     数量增减，可用 {step}（1）和 {big}（10）
     qty set 8          数量直接设成 8
     page 1 / page -1   翻页
     buy                购买
     cancel             取消选择
     open 灵材          切换到别的商店
     close              关闭界面
     hint               提示「用箭头调数量」

六、改完怎么生效
   /shop reload
   界面每次打开都会重新读文件，所以多数情况改完直接重开就行。

七、其它字段
   size: [760, 414]   界面宽高，不写就用商店 layout 的尺寸
   rows: 4            画了几行商品，不写就用商店 layout.rows
   加行：复制「行4」那一整段，把行4 改成行5，再把所有 y 值加 54。

八、想只给某个商店单独做界面
   1. 复制 默认.yml 成 我的界面.yml
   2. 把 match 改成商店名，比如 match: "测试"
   3. 打开 /shop 测试 就是新界面了
